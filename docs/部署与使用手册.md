## 5. 参数详解

### 5.1 命令行选项

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `-y, --yes` | 全自动安装，不询问 | 关 |
| `-p, --port <端口>` | Reality 对外端口 | `443` |
| `-n, --network <tcp\|xhttp>` | Reality 网络模式 | `tcp`（vision） |
| `-d, --domain <域名>` | 域名 self-steal 伪装（需 DNS 已指向本机） | 无 |
| `-e, --email <邮箱>` | ACME 证书邮箱（配合 `-d`） | 无 |
| `-u, --uuid <UUID>` | 自定义 UUID（默认自动生成） | 自动 |
| `-P, --proxy <URL>` | 后置代理 `socks5://` 或 `http://`（可含账密） | 无 |
| `-x, --no-3xui` | 不安装 3X-UI 面板 | 装 |
| `-b, --no-bbr` | 跳过 BBR 与内核优化 | 不跳 |
| `-c, --no-docker` | 跳过 Docker 安装（已装时） | 不跳 |
| `-r, --no-rules` | 跳过 v2ray-rules-dat 下载 | 不跳 |
| `-m, --mirror` | 国内加速：Docker 安装脚本与 `daemon.json` registry-mirrors；GitHub/ghcr 代理在拉取失败时始终回退，不依赖本开关 | 关 |
| `--xui-user <用户>` | 3X-UI 登录用户（`install` / `cluster-token`） | `admin` |
| `--xui-pass <密码>` | 3X-UI 登录密码（同上） | `admin` |
| `-h, --help` | 显示帮助 | — |

### 5.2 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `INSTALL_DIR` | 安装目录 | `/opt/xray-oneclick` |
| `REALITY_IMAGE` | Reality 镜像 | `wulabing/xray_docker_reality:latest` |
| `XUI_IMAGE` | 3X-UI 镜像 | `ghcr.io/mhsanaei/3x-ui:latest` |
| `XUI_PORT` | 3X-UI 面板端口 | `2053` |
| `SHORTIDS` | Reality shortId（空格分隔 hex） | 空 |
| `MIN_CLIENT_VER` | 最低客户端版本 | 镜像默认 `1.0.0` |
| `XUI_BASE_PATH` | 3X-UI 面板路径（默认随机） | 随机 `/xui-xxxxxxxx` |
| `XUI_USER` / `XUI_PASS` | 3X-UI 登录凭据（`install` 经 `x-ui setting` 写入；亦用于 `cluster-token`） | `admin` / `admin` |
| `NODE_EXTRA_PORTS` | Reality 容器额外 `-p` 映射，空格分隔；约定 `host:container`，裸数字自动扩成 `N:N` | 空 |

### 6.2 `update-rules` — 更新 v2ray-rules-dat

```bash
sudo bash install.sh update-rules
```

- 重新下载 `geoip.dat` / `geosite.dat` 并做 sha256 校验
- 重启 Reality 节点；若存在 `3x-ui/run.sh` 则**重建**面板容器以便运行时挂载新规则文件
- 自动重启所有 Reality 容器与 3X-UI 面板容器加载新规则（xray 仅在进程启动时读取规则文件）
- 系统也会通过 cron（每周三 04:15）自动执行
