## 1. 项目概述

本脚本用于在一台 Linux 服务器上一键部署完整的 **VLESS Reality 代理节点 + 3X-UI 管理面板**，采用 xray reality docker 镜像前置架构，开箱即用。

### 1.1 功能特性

| 特性 | 说明 |
| --- | --- |
| 🚀 Reality 前置节点 | 官方 `wulabing/xray_docker_reality` 镜像，端口 443 承载 VLESS Reality（`tcp`/vision 或 `xhttp` 双模式） |
| ⚡ BBR 内核优化 | BBR 拥塞控制 + `fq` 队列 + 全套 TCP/UDP/conntrack 参数，OpenVZ/旧内核自动检测回退 |
| 🗺️ 路由规则加强 | [Loyalsoldier/v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat) 的 `geoip.dat`/`geosite.dat` 挂载进 Reality 容器与 3X-UI 面板（sha256 校验），每周自动更新 |
| 🎭 协议伪装 | 使用 [SERVERNAMES_ZH.MD](https://github.com/wulabing/xray_docker/blob/master/reality/SERVERNAMES_ZH.MD) 已知站点列表作为 Reality DEST/SNI；支持域名 self-steal（自动签发证书并托管伪装站点） |
| 🖥️ 3X-UI 后台 | [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui) Docker 部署：多节点管理、订阅、二维码、流量统计、证书管理 |
| 🔗 本机多前置节点 | `add-node` 再起 Reality **容器**（与面板入站不是同一套） |
| 🖥️ 多机主从 | `cluster-token` / `cluster-add-node` / `cluster-share` / `cluster-status` 调 3X-UI API |
| 📱 多种订阅 | 终端内 UTF8 二维码 + vless 链接 + 3X-UI 订阅；`sub-server` 带随机路径令牌 |

### 1.2 架构图

```
                          ┌─────────────────────────────┐
  客户端 vless://... ────► │  wulabing/xray_docker_reality │  端口 443
   (Reality TLS 握手)     │  ┌─────────────────────────┐  │
                          │  │ dokodemo-door(SNI嗅探) │  │
                          │  │   ├─ 匹配 SNI → vless-in│  │  VLESS Reality
                          │  │   └─ 不匹配  → blocked │  │  (tcp/vision | xhttp)
                          │  └─────────────────────────┘  │
                          │  Caddy (可选 self-steal 站点)  │  端口 80/8443
                          │  路由: v2ray-rules-dat 规则    │
                          └──────────────┬──────────────┘
                                         │
  管理面板 ─────────────────────────► 3X-UI (Docker)        端口 2053
  (多节点/订阅/二维码/统计)                                    + 自定入站端口
```

> 443 前置容器由 `install.sh` 管理；2053 面板是另一套 xray。`add-node` 只加本机容器，跨机器请用第 16 章 / `cluster-*`。

### 1.3 参考项目

- [wulabing/xray_docker](https://github.com/wulabing/xray_docker) — Reality Docker 镜像
- [XTLS/Xray-core](https://github.com/XTLS/Xray-core) — 代理内核

## 2. 环境要求

### 2.1 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Debian 10+ / Ubuntu 18.04+ / CentOS 7+ / Rocky / AlmaLinux / Fedora / Alpine |
| 架构 | x86_64 / arm64 / armv7 |
| 权限 | root（脚本会自动检查） |
| 磁盘 | ≥ 2 GB 空闲 |
| 内存 | ≥ 512 MB（推荐 1 GB+） |
| 网络 | 可访问 Docker Hub / GitHub（受限时可加 `-m` 使用国内镜像） |

> 虚拟化：KVM/Xen 均可开启 BBR；**OpenVZ/LXC** 无法启用 BBR，脚本会自动检测并跳过，不影响安装。

### 2.2 端口规划

| 端口 | 用途 | 说明 |
| --- | --- | --- |
| 443 | Reality 节点主端口 | 可自定义（`-p`） |
| 80 | 域名 self-steal 模式 ACME 验证 | 仅 `-d` 时占用 |
| 2053 | 3X-UI 面板 Web | 可自定义（`XUI_PORT` 环境变量） |
| 其他 | 3X-UI 面板内新增的入站端口 | 用 `xui-port` 命令放行 |

## 3. 快速部署

### 3.1 方式一：一行命令（推荐）

```bash
# 推荐: Release 完整包 (含 lib/ conf/)
curl -fsSL -o xray-oneclick.tar.gz \
  https://github.com/richma/xray-oneclick/releases/latest/download/xray-oneclick.tar.gz
tar -xzf xray-oneclick.tar.gz && cd xray-oneclick
sudo bash install.sh -y

# 或只下入口脚本（之后可继续使用 install.sh 的子命令）
curl -fsSL -o install.sh https://raw.githubusercontent.com/richma/xray-oneclick/main/install.sh
chmod +x install.sh
sudo bash install.sh -y          # 全自动安装，默认参数
```

### 3.2 方式二：一行管道（仅完成安装）

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/richma/xray-oneclick/main/install.sh) -y
```

> 注意：管道方式会临时下载完整仓库（含 `lib/`、`conf/`），安装结束后副本在 `/opt/xray-oneclick/`。离线环境请 `git clone`。后续子命令请使用 `/opt/xray-oneclick/install.sh`。

### 3.3 方式三：交互式菜单

```bash
sudo bash install.sh
```

显示菜单：

```

║    Xray Reality (Docker) + 3X-UI 一键安装 v1.0.0           ║
╚════════════════════════════════════════════════════════════╝
  1) 一键安装 (BBR + Docker + Reality + 3X-UI + 规则)
  2) 仅 BBR + 内核网络优化
  3) 仅安装 Docker
  4) 仅安装 Reality 节点
  5) 仅安装 3X-UI 面板

  9) 3X-UI 开放端口
```

### 3.4 安装过程各步骤

1. **环境检测**：系统 / 架构 / 虚拟化 / 网络连通性
2. **BBR + 内核优化**：写入 `/etc/sysctl.d/99-xray-optimize.conf` 并即时生效
3. **Docker 安装**：官方脚本安装 Docker + Compose 插件（`-m` 时走阿里云镜像）
4. **伪装站点选择**：自动拉取 `SERVERNAMES_ZH.MD` 列表供选择（默认 Apple 站点）
5. **Reality 节点部署**：生成 UUID/密钥对 → 拉取镜像 → 启动容器 → 注入增强路由配置 → 挂载 v2ray-rules-dat 规则文件
6. **3X-UI 部署**：拉取镜像 → 生成随机访问路径 → 启动面板
7. **定时任务**：每周三 04:15 自动更新路由规则
8. **防火墙**：自动放行所需端口（ufw / firewalld / iptables）

安装完成后自动打印节点配置信息（含 vless 链接与二维码）与 3X-UI 面板信息。

## 5. 参数详解

### 5.1 命令行选项

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `-y, --yes` | 全自动安装，不询问 | 关 |
| `-p, --port <端口>` | Reality 对外端口 | `443` |
| `-n, --network <tcp\|xhttp>` | Reality 网络模式 | `tcp`（vision） |
| `-d, --domain <域名>` | 域名 self-steal 伪装（需 DNS 已指向本机） | 无 |
| `-e, --email <邮箱>` | ACME 证书邮箱（配合 `-d`） | 无 |
| `-u, --uuid <UUID>` | 自定义 UUID（默认自动生成） | 自动 |
| `-P, --proxy <URL>` | 后置代理 `socks5://` 或 `http://`（可含账密） | 无 |
| `-x, --no-3xui` | 不安装 3X-UI 面板 | 装 |
| `-b, --no-bbr` | 跳过 BBR 与内核优化 | 不跳 |
| `-c, --no-docker` | 跳过 Docker 安装（已装时） | 不跳 |
| `-r, --no-rules` | 跳过 v2ray-rules-dat 下载 | 不跳 |
| `-m, --mirror` | 国内加速：Docker 安装脚本与 `daemon.json` registry-mirrors；GitHub/ghcr 代理在拉取失败时始终回退，不依赖本开关 | 关 |
| `--xui-user <用户>` | 3X-UI 登录用户（`install` / `cluster-token`） | `admin` |
| `--xui-pass <密码>` | 3X-UI 登录密码（同上） | `admin` |
| `-h, --help` | 显示帮助 | — |

### 5.2 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `INSTALL_DIR` | 安装目录 | `/opt/xray-oneclick` |
| `REALITY_IMAGE` | Reality 镜像 | `wulabing/xray_docker_reality:latest` |
| `XUI_IMAGE` | 3X-UI 镜像 | `ghcr.io/mhsanaei/3x-ui:latest` |
| `XUI_PORT` | 3X-UI 面板端口 | `2053` |
| `SHORTIDS` | Reality shortId（空格分隔 hex） | 空 |
| `MIN_CLIENT_VER` | 最低客户端版本 | 镜像默认 `1.0.0` |
| `XUI_BASE_PATH` | 3X-UI 面板路径（默认随机） | 随机 `/xui-xxxxxxxx` |
| `XUI_USER` / `XUI_PASS` | 3X-UI 登录凭据（`install` 经 `x-ui setting` 写入；亦用于 `cluster-token`） | `admin` / `admin` |
| `NODE_EXTRA_PORTS` | Reality 容器额外 `-p` 映射，空格分隔；约定 `host:container`，裸数字自动扩成 `N:N` | 空 |

## 6. 子命令使用

### 6.1 `add-node` — 添加更多 Reality 节点（多节点）

```bash
sudo bash install.sh add-node -p 8443 -y
```

- 自动生成新的 UUID / 密钥对，独立容器（`xray_reality_8443`）、独立数据目录
- 自动继承第一个节点的伪装站点与网络模式配置
- 新节点链接自动追加进 `subscription.txt`
- 可指定不同网络模式：`add-node -p 8443 -n xhttp`

### 6.2 `update-rules` — 更新 v2ray-rules-dat

```bash
sudo bash install.sh update-rules
```

- 重新下载 `geoip.dat` / `geosite.dat` 并做 sha256 校验
- 重启 Reality 节点；若存在 `3x-ui/run.sh` 则**重建**面板容器以便运行时挂载新规则文件
- 自动重启所有 Reality 容器与 3X-UI 面板容器加载新规则（xray 仅在进程启动时读取规则文件）
- 系统也会通过 cron（每周三 04:15）自动执行

### 6.3 `info` — 查看节点信息

```bash
sudo bash install.sh info
```

显示所有节点状态、配置信息、二维码与订阅汇总。

### 6.4 `xui-port` — 3X-UI 开放端口

在 3X-UI 面板内新增入站后，需要在宿主机发布对应端口：

```bash
sudo bash install.sh xui-port 8388        # 可一次开放多个
sudo bash install.sh xui-port 8388 8389
```

### 6.5 `uninstall` — 卸载

```bash
sudo bash install.sh uninstall
```

按提示依次确认：卸载容器与系统配置 → 是否删除数据目录 → 是否卸载 Docker。

### 6.6 `panel-proxy` — 面板 HTTPS 反向代理

```bash
sudo bash install.sh panel-proxy -d panel.example.com                # 基础 HTTPS
sudo bash install.sh panel-proxy -d panel.example.com --panel-pass 密码   # 加登录密码
sudo bash install.sh panel-proxy -d panel.example.com --panel-port 2083   # 自定义端口
```

- 用 Caddy 自动签发/续期 Let's Encrypt 证书，`https://panel.example.com:9443/<面板路径>/` 访问面板
- **前端节点已配置域名时自动复用其 Caddy**（Caddyfile 注入面板反代站点，同域名同证书，避免 80 端口冲突）；否则使用独立 Caddy 容器（需宿主机 80 空闲）
- 要求：域名 A 记录指向本机；云防火墙放行 `80`（ACME）与反代端口
- 反代层密码与面板登录密码是两层，可同时启用

### 6.7 `sub-server` — 节点订阅 HTTP 服务（HTTP 分享节点链接）

```bash
sudo bash install.sh sub-server                # 默认 8080 端口
sudo bash install.sh sub-server --sub-port 8081
```

- 用 busybox httpd 将本机 `subscription.txt` 放到**随机路径令牌**下：
  `http://<本机IP>:8080/<token>/subscription.txt`
- 令牌写入 `/opt/xray-oneclick/sub-server.token`（`chmod 600`）。可用 `--sub-token` 指定。
- 不要把该 URL 提交到 git 或发到公开聊天。
- 用途：主面板「外部订阅」聚合本机前置节点；多机统一管理见第 16 章
- 要求：云防火墙放行 8080；能访问该 URL 的人就能拿到 vless 链接

### 6.8 集群子命令（3X-UI 主从）

前置 Reality 容器 **不能** 被主从系统管理。下面操作的是**每台机器上的 3X-UI 面板**。

```bash
# ① 子节点：登录本地面板，签发 node-sync Token（只显示一次）
sudo bash install.sh cluster-token --xui-user admin --xui-pass '面板密码'

# ② 主节点：注册子节点
sudo bash install.sh cluster-add-node \
  --node-name kr --node-address kr.example.com --node-port 2053 \
  --node-path /xui-xxxx --node-token '<① 的 Token>' \
  --node-scheme http --allow-private

# ③ 每台（含主节点）：给当前面板全部入站加上同一 UUID / subId 的共享客户端
sudo bash install.sh cluster-share --share-email main --share-subid main --share-uuid '<同一UUID>'

# ④ 主节点：查看子节点在线/延迟
sudo bash install.sh cluster-status

# ⑤ 可选：订阅里用域名而不是 IP
sudo bash install.sh cluster-host --host-inbound 1 --host-addr sg.example.com:443 --host-remark 'SG'
```

面板账号也可用 `--xui-token`（Bearer）代替用户名密码。HTTPS 自签证书默认 `tlsVerifyMode=skip`，若要校验请加 `--tls-verify`。

## 7. 客户端配置

SEE_FULL_FILE_IN_LOCAL_CLONE
