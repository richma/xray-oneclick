## 1. 项目概述

本脚本用于在一台 Linux 服务器上一键部署完整的 **VLESS Reality 代理节点 + 3X-UI 管理面板**，采用 xray reality docker 镜像前置架构，开箱即用。

### 1.1 功能特性

| 特性 | 说明 |
| --- | --- |
| 🚀 Reality 前置节点 | 官方 `wulabing/xray_docker_reality` 镜像，端口 443 承载 VLESS Reality（`tcp`/vision 或 `xhttp` 双模式） |
| ⚡ BBR 内核优化 | BBR 拥塞控制 + `fq` 队列 + 全套 TCP/UDP/conntrack 参数，OpenVZ/旧内核自动检测回退 |
| 🗺️ 路由规则加强 | [Loyalsoldier/v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat) 的 `geoip.dat`/`geosite.dat` 挂载进容器（sha256 校验），每周自动更新 |
| 🎭 协议伪装 | 使用 [SERVERNAMES_ZH.MD](https://github.com/wulabing/xray_docker/blob/master/reality/SERVERNAMES_ZH.MD) 已知站点列表作为 Reality DEST/SNI；支持域名 self-steal（自动签发证书并托管伪装站点） |
| 🖥️ 3X-UI 后台 | [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui) Docker 部署：多节点管理、订阅、二维码、流量统计、证书管理 |
| 🔗 多节点 | `add-node` 一条命令添加更多 Reality 节点（自动生成 UUID/密钥，互不干扰） |
| 📱 多种订阅 | 终端内 UTF8 二维码 + vless 链接 + 3X-UI 订阅链接（Base64/Clash/sing-box 格式） |

### 1.2 架构图

```
                          ┌─────────────────────────────┐
  客户端 vless://... ────► │  wulabing/xray_docker_reality │  端口 443
   (Reality TLS 握手)     │  ┌─────────────────────────┐  │
                          │  │ dokodemo-door(SNI嗅探) │  │
                          │  │   ├─ 匹配 SNI → vless-in│  │  VLESS Reality
                          │  │   └─ 不匹配  → blocked │  │  (tcp/vision | xhttp)
                          │  └─────────────────────────┘  │
                          │  Caddy (可选 self-steal 站点)  │  端口 80/8443
                          │  路由: v2ray-rules-dat 规则    │
                          └──────────────┬──────────────┘
                                         │
  管理面板 ─────────────────────────► 3X-UI (Docker)        端口 2053
  (多节点/订阅/二维码/统计)                                    + 自定入站端口
```

### 1.3 参考项目

- [wulabing/xray_docker](https://github.com/wulabing/xray_docker) — Reality Docker 镜像
- [XTLS/Xray-core](https://github.com/XTLS/Xray-core) — 代理内核
- [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui) — 管理面板
- [Loyalsoldier/v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat) — 路由规则文件

## 2. 环境要求

### 2.1 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Debian 10+ / Ubuntu 18.04+ / CentOS 7+ / Rocky / AlmaLinux / Fedora / Alpine |
| 架构 | x86_64 / arm64 / armv7 |
| 权限 | root（脚本会自动检查） |
| 磁盘 | ≥ 2 GB 空闲 |
| 内存 | ≥ 512 MB（推荐 1 GB+） |
| 网络 | 可访问 Docker Hub / GitHub（受限时可加 `-m` 使用国内镜像） |

> 虚拟化：KVM/Xen 均可开启 BBR；**OpenVZ/LXC** 无法启用 BBR，脚本会自动检测并跳过，不影响安装。

### 2.2 端口规划

| 端口 | 用途 | 说明 |
| --- | --- | --- |
| 443 | Reality 节点主端口 | 可自定义（`-p`） |
| 80 | 域名 self-steal 模式 ACME 验证 | 仅 `-d` 时占用 |
| 2053 | 3X-UI 面板 Web | 可自定义（`XUI_PORT` 环境变量） |
| 其他 | 3X-UI 面板内新增的入站端口 | 用 `xui-port` 命令放行 |

## 3. 快速部署

### 3.1 方式一：一行命令（推荐）

```bash
# 下载后执行（之后可继续使用 install.sh 的子命令）
curl -fsSL -o install.sh https://raw.githubusercontent.com/richma/xray-oneclick/main/install.sh
chmod +x install.sh
sudo bash install.sh -y          # 全自动安装，默认参数
```

### 3.2 方式二：一行管道（仅完成安装）

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/richma/xray-oneclick/main/install.sh) -y
```

> 注意：管道方式运行时脚本不落盘，`info`/`add-node` 等子命令请使用方式一。

### 3.3 方式三：交互式菜单

```bash
sudo bash install.sh
```

显示菜单：

```
╔════════════════════════════════════════════════════════════╗
║    Xray Reality (Docker) + 3X-UI 一键安装 v1.0.0           ║
╚════════════════════════════════════════════════════════════╝
  1) 一键安装 (BBR + Docker + Reality + 3X-UI + 规则)
  2) 仅 BBR + 内核网络优化
  3) 仅安装 Docker
  4) 仅安装 Reality 节点
  5) 仅安装 3X-UI 面板
  6) 添加更多 Reality 节点 (多节点)
  7) 更新 v2ray-rules-dat 规则
  8) 查看节点信息 / 订阅 / 二维码
  9) 3X-UI 开放端口
  10) 卸载
```

### 3.4 安装过程各步骤

1. **环境检测**：系统 / 架构 / 虚拟化 / 网络连通性
2. **BBR + 内核优化**：写入 `/etc/sysctl.d/99-xray-optimize.conf` 并即时生效
3. **Docker 安装**：官方脚本安装 Docker + Compose 插件（`-m` 时走阿里云镜像）
4. **伪装站点选择**：自动拉取 `SERVERNAMES_ZH.MD` 列表供选择（默认 Apple 站点）
5. **Reality 节点部署**：生成 UUID/密钥对 → 拉取镜像 → 启动容器 → 注入增强路由配置 → 挂载 v2ray-rules-dat 规则文件
6. **3X-UI 部署**：拉取镜像 → 生成随机访问路径 → 启动面板
7. **定时任务**：每周三 04:15 自动更新路由规则
8. **防火墙**：自动放行所需端口（ufw / firewalld / iptables）

安装完成后自动打印节点配置信息（含 vless 链接与二维码）与 3X-UI 面板信息。

## 5. 参数详解

### 5.1 命令行选项

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `-y, --yes` | 全自动安装，不询问 | 关 |
| `-p, --port <端口>` | Reality 对外端口 | `443` |
| `-n, --network <tcp\|xhttp>` | Reality 网络模式 | `tcp`（vision） |
| `-d, --domain <域名>` | 域名 self-steal 伪装（需 DNS 已指向本机） | 无 |

| `-x, --no-3xui` | 不安装 3X-UI 面板 | 装 |
| `-b, --no-bbr` | 跳过 BBR 与内核优化 | 不跳 |
| `-c, --no-docker` | 跳过 Docker 安装（已装时） | 不跳 |
| `-r, --no-rules` | 跳过 v2ray-rules-dat 下载 | 不跳 |
| `-m, --mirror` | 使用国内镜像（Docker 安装/镜像拉取/GitHub 下载） | 关 |
| `-h, --help` | 显示帮助 | — |

### 5.2 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `INSTALL_DIR` | 安装目录 | `/opt/xray-oneclick` |
| `REALITY_IMAGE` | Reality 镜像 | `wulabing/xray_docker_reality:latest` |

## 6. 子命令使用

### 6.1 `add-node` — 添加更多 Reality 节点（多节点）

```bash
sudo bash install.sh add-node -p 8443 -y
```

- 自动生成新的 UUID / 密钥对，独立容器（`xray_reality_8443`）、独立数据目录
- 自动继承第一个节点的伪装站点与网络模式配置
- 新节点链接自动追加进 `subscription.txt`
- 可指定不同网络模式：`add-node -p 8443 -n xhttp`

### 6.2 `update-rules` — 更新 v2ray-rules-dat

```bash
sudo bash install.sh update-rules
```

- 重新下载 `geoip.dat` / `geosite.dat` 并做 sha256 校验
- 自动重启所有 Reality 容器加载新规则
- 系统也会通过 cron（每周三 04:15）自动执行

### 6.3 `info` — 查看节点信息

```bash
sudo bash install.sh info
```

显示所有节点状态、配置信息、二维码与订阅汇总。

### 6.4 `xui-port` — 3X-UI 开放端口

在 3X-UI 面板内新增入站后，需要在宿主机发布对应端口：

```bash
sudo bash install.sh xui-port 8388        # 可一次开放多个
sudo bash install.sh xui-port 8388 8389
```

### 6.5 `uninstall` — 卸载

```bash
sudo bash install.sh uninstall
```

按提示依次确认：卸载容器与系统配置 → 是否删除数据目录 → 是否卸载 Docker。

## 7. 客户端配置

### 7.1 链接格式解读

**tcp / vision 模式：**

```
vless://UUID@服务器IP:443?encryption=none&security=reality&type=tcp&sni=images.apple.com&fp=firefox&pbk=公钥&flow=xtls-rprx-vision#节点名
```

**xhttp 模式：**

```
vless://UUID@服务器IP:443?encryption=none&security=reality&type=xhttp&sni=images.apple.com&fp=firefox&pbk=公钥&path=/随机路径&mode=auto#节点名
```

关键参数对照：

| 链接参数 | 含义 | 获取方式 |
| --- | --- | --- |
| `UUID` | 客户端 ID | 安装输出 / `info` |
| `pbk` | Reality 公钥（Password） | 安装输出 / `info` |
| `sni` | 伪装 SNI（取 SERVERNAMES 第一个） | 安装输出 / `info` |
| `fp` | TLS 指纹（默认 firefox） | 固定 |
| `flow` | 流控（vision 用 `xtls-rprx-vision`） | tcp 模式固定 |
| `sid` | shortId（可选） | 设置了 `SHORTIDS` 时出现 |

### 7.2 v2rayN（Windows）

1. 打开 v2rayN → 服务器 → 从剪贴板导入批量 URL
2. 复制 `info` 输出的 vless 链接，或直接扫终端二维码
3. 选中节点 → 设为活动服务器

### 7.3 v2rayNG（Android）

1. 右上角 `+` → 从剪贴板导入 / 扫描二维码
2. 选择节点 → 连接

### 7.4 sing-box（全平台）

```json
{
  "outbounds": [
    {
      "type": "vless",
      "tag": "reality",
      "server": "服务器IP",
      "server_port": 443,
      "uuid": "你的UUID",
      "flow": "xtls-rprx-vision",
      "tls": {
        "enabled": true,
        "server_name": "images.apple.com",
        "utls": { "enabled": true, "fingerprint": "firefox" },
        "reality": { "enabled": true, "public_key": "你的公钥", "short_id": "" }
      }
    }
  ]
}
```

### 7.5 Shadowrocket / Stash（iOS）

直接扫码或粘贴 vless 链接即可；xhttp 模式需客户端内核支持（Shadowrocket 2.x+ / sing-box 内核）。

## 8. 3X-UI 面板使用指南

### 8.1 首次登录

1. 浏览器访问 `http://<服务器IP>:2053/<随机路径>`
2. 账号 `admin` / 密码 `admin` 登录
3. **立即修改**：面板设置 → 修改用户名、密码、面板端口与访问路径
   - 修改面板端口后需重新发布：`sudo bash install.sh xui-port <新端口>` 前先调整 `XUI_PORT`
   - 修改访问路径后，用新路径访问

### 8.2 添加入站（新节点）

1. 入站列表 → 添加入站
2. 选择协议（VLESS/VMess/Trojan/Shadowsocks...），配置端口、UUID、传输方式（可同样使用 Reality）
3. 保存后，在宿主机放行端口：
   ```bash
   sudo bash install.sh xui-port <入站端口>
   ```

### 8.3 添加客户端与订阅

1. 入站列表 → 展开入站 → 添加客户端
2. 客户端支持一键生成：**订阅（链接/二维码）**
3. 订阅设置支持：
   - Base64 / Clash / sing-box 多种订阅格式
   - 订阅路径自定义（面板设置 → 订阅设置）
   - 多客户端聚合订阅

### 8.4 域名 + HTTPS 证书（面板）

面板设置 → 域名设置：填入域名并上传证书，或使用面板内置 acme 自动申请，即可通过 `https://域名:端口` 访问面板。

### 8.5 流量统计

面板首页实时显示在线用户、各节点/客户端流量、连接数；可设置流量上限与到期时间。

## 9. 域名 self-steal 伪装

Reality 默认"借用"真实站点（如 `www.apple.com`）完成 TLS 握手。若你拥有自己的域名，可开启 self-steal 模式，让客户端握手到**你自己托管的站点**，隐蔽性更高：

```bash
sudo bash install.sh -d vpn.example.com -e you@mail.com
```

前置条件与说明：

1. 将域名 A 记录解析到服务器 IP（支持 IPv6 则加 AAAA）
2. 脚本自动配置容器内置 Caddy 为域名签发 Let's Encrypt 证书并托管默认站点
3. Reality 的 DEST/SNI 自动切换为你的域名
4. 首次签发证书需等待数秒至数十秒
5. 需要放行 **80 与 443** 端口

**自定义伪装页面**：挂载自己的静态站点目录覆盖容器默认页：

```bash
sudo docker run -d --name xray_reality --restart=always \
  -p 443:443 -p 80:80 \
  -e DOMAIN="vpn.example.com" \
  -v "$(pwd)/my_site:/srv/www" \
  -v /opt/xray-oneclick/nodes/node_443/data:/data \
  -v /opt/xray-oneclick/conf/xray-config.template.json:/config.template.json:ro \
  -v /opt/xray-oneclick/nodes/node_443/entrypoint-wrapper.sh:/entrypoint-wrapper.sh:ro \
  --entrypoint /entrypoint-wrapper.sh \
  wulabing/xray_docker_reality:latest
```

> 推荐伪装页面带中文标题与备案号风格内容，更贴近真实站点。

## 10. 路由规则说明（v2ray-rules-dat）

### 10.1 规则文件

- `geoip.dat` / `geosite.dat` 来自 [Loyalsoldier/v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat)，GitHub Actions 每日 06:00（北京时间）自动构建，规则最新
- 相比官方规则新增：`geoip:cloudflare`、`geoip:netflix`、`geoip:telegram`、`geosite:gfw`、`geosite:category-ads-all` 等大量类别
- 本脚本每周三 04:15 自动更新（cron：`/etc/cron.d/xray-rules-update`）

### 10.2 内置增强路由规则（`conf/xray-config.template.json`）

| 优先级 | 规则 | 动作 | 说明 |
| --- | --- | --- | --- |
| 1 | dokodemo-in + 匹配 SNI | direct | Reality 客户端 SNI 分流到 vless |
| 2 | dokodemo-in 其他 | blocked | 非目标 SNI 一律黑洞（防扫描） |
| 3 | api 入站 | api | 面板统计 |
| 4 | `geosite:category-ads-all` | blocked | 广告/隐私追踪域名拦截 |
| 5 | `geosite:private` | direct | 内网/保留域名直连 |
| 6 | `geoip:private` | direct | 内网 IP 直连 |
| 7 | `geosite:cn` | direct | 中国大陆域名直连 |
| 8 | `geoip:cn` | direct | 中国大陆 IP 直连 |
| 9 | bittorrent | blocked | BT 下载拦截 |

> 结合 `-P` 后置代理使用时：除上述规则外，其余流量全部走后置代理出站（实现"国内直连 + 海外家宽 IP"分流）。

### 10.3 自定义路由规则

编辑模板后重建节点即可生效：

```bash
sudo vim /opt/xray-oneclick/conf/xray-config.template.json
sudo bash /opt/xray-oneclick/install.sh install -y    # 重建节点（密钥保持不变）
```

## 11. 后置代理（家宽 IP）

适用场景：解锁 Netflix / ChatGPT / AI 支付等对 IP 纯净度要求高的服务。

```bash
sudo bash install.sh -P "socks5://user:pass@1.2.3.4:1080"   # socks5
sudo bash install.sh -P "http://user:pass@10.0.0.1:8080"     # http
```

- 启用后，除 `geoip:cn`、`geoip:private`、广告拦截等规则外的流量全部经后置代理出站
- 可配合 [Proxy-Cheap](https://app.proxy-cheap.com/r/Pbqf9l) / [IPRoyal](https://iproyal.cn/?r=249487) 等家宽代理服务
- 已配置节点的代理变更：重建节点即可（`install.sh install -y` 会复用原密钥）

### 12.2 常见问题（FAQ）

**Q1：安装后连不上？**
1. 检查云厂商安全组是否放行端口（443 / 2053 / 自定义节点端口）
2. `sudo bash install.sh info` 确认节点状态为"运行中"
3. `docker logs xray_reality` 查看容器日志
4. 客户端确认 UUID / 公钥 / SNI 与 `info` 输出一致

**Q2：端口被占用？**
```bash
sudo bash install.sh -p 8443    # 换端口重装
```

**Q3：国内服务器拉取镜像超时？**
```bash
sudo bash install.sh -m         # 使用国内镜像（docker 加速 + ghcr 镜像 + GitHub 代理）
```

**Q4：BBR 未生效？**
- OpenVZ/LXC 虚拟化不支持，属正常现象
- KVM 环境执行 `sysctl net.ipv4.tcp_congestion_control`，应输出 `bbr`

**Q5：3X-UI 面板打不开？**
- 确认 2053 已放行；访问路径以 `info.txt` 为准（随机生成 `/xui-xxxxxxxx`）
- 曾安装过 3X-UI 的服务器，路径以旧数据库为准

**Q6：面板内新增入站后连不上？**
- 先运行 `sudo bash install.sh xui-port <端口>` 发布端口，再检查安全组

**Q7：想重新生成节点密钥？**
```bash
sudo docker rm -f xray_reality
sudo rm -rf /opt/xray-oneclick/nodes/node_443
sudo bash install.sh -y
```

**Q8：如何确认 Reality 伪装正常？**
```bash
echo | openssl s_client -connect 服务器IP:443 -servername images.apple.com 2>/dev/null | grep subject=
# 应显示 Apple 等目标站点的真实证书信息
```

## 13. 安全建议

1. **立即修改 3X-UI 默认密码**（admin/admin）并设置随机访问路径
2. 面板尽量通过 `https://域名:端口` 访问（面板设置中配置证书）
3. 不要将 `nodes.ini`、`reality_state.json`、`config_info.txt` 等含私钥的文件外泄
4. 生产环境建议：
   - 使用非 443 高位端口部署面板（`XUI_PORT`）
   - 限制面板登录 IP（面板设置 → 安全设置）
   - 定期更新系统与镜像（`update-rules` 已覆盖规则文件；镜像可 `docker pull` 后重建）
5. SSH 建议仅密钥登录；如启用防火墙，脚本已自动放行所需端口
