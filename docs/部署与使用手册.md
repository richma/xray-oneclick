## P1/P2 相关修订摘要

- `-m`：仅影响 Docker 安装 / `daemon.json`；GitHub/ghcr 代理始终作为失败回退。
- `--xui-user` / `--xui-pass`：`install` 会经 `x-ui setting` 写入面板凭据。
- `update-rules`：存在 `3x-ui/run.sh` 时重建面板容器以挂载新规则。
- `NODE_EXTRA_PORTS`：约定 `host:container`，裸数字扩成 `N:N`。
