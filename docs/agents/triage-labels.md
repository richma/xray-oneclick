# Triage 标签

各 skill 用五个规范 triage 角色表达意图。本文件把这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 中的 label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

skill 提到某个角色时（例如“apply the AFK-ready triage label”），使用本表中对应的 label 字符串。

右列改成你们实际使用的词汇即可。
